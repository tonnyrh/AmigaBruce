# Enhanced graphics edits

The editor saves one indexed PNG per edited asset here. The packer uses the original image for every asset without an edit. Each PNG records the asset ID, the original image hash and the origin of the edit. Include these files in Git to share the artwork.

Use **Import image** to bring in artwork from another tool. The editor fits it to the asset dimensions, palette and silhouette before showing the preview. [Editor guide](../../../docs/GRAPHICS_EDITOR.md).
